# 音帝庙大冒险

拖动摇杆移动、自动射箭的闯关 Roguelike（弓箭传说 / Archero 玩法复刻）。

- 🎮 在线玩：https://dsosy.github.io/archery-legend/
- 🔗 **技能跨关卡继承**：打过的技能、等级与生命一路带到下一关，阵亡才重新开始
- 👥 **双人同屏**：左半屏 = P1、右半屏 = P2，一根手指一人
- ⚔ **好友挑战**：生成同种子的挑战链接，比谁在无尽模式走得远
- 🏹 35 个技能**只增不减、可反复叠加**（重复选同一技能即提升层数，卡面/技能栏/暂停页都显示当前层数与实际效果）
- ⚔ 5 把武器、3 章 ×10 关 + BOSS、永久强化、无尽模式

手机浏览器打开即玩，建议「添加到主屏幕」全屏游玩。单文件 H5，无外部依赖。
