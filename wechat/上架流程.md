## 阶段 0 · 开工前的现实认知（先看这段，避免白忙）

| 事项 | 说明 |
| --- | --- |
| **必须有账号** | 小游戏只能在微信公众平台注册，个人主体可以注册，但要实名 |
| **必须有备案** | 2023 年起国内游戏（含小游戏）上架需**版号或游戏备案**。个人主体走「免版号 + 备案」路径 |
| **不能内购** | 个人主体没有虚拟支付权限，游戏里不能有付费。想变现只能后期接激励视频广告（需「流量主」，1000+ 用户） |
| **审核会看内容** | 名称不能蹭 IP、不能有违规元素、要有隐私说明 |
| **本游戏的优势** | 纯单机、**完全不联网**、**不收集任何个人信息**、无账号体系、无支付、无 UGC —— 这几条正好是审核最省事的形态 |

## 阶段 2 · 游戏备案（**最耗时的一步**）

> 这是唯一可能卡住的地方。个人开发者可以备案，但需要提交材料并等省级出版管理部门审核（常见 5～20 个工作日）。
> 政策以微信公众平台/属地出版局最新要求为准，下面是通用流程。

🧑 **2.1 在微信后台提交备案**
- 后台 →「设置」→「基本设置」→ 找到 **游戏备案 / 备案信息** 入口（不同时期入口位置会变）
- 备案类型选择：**国产网络游戏备案**（无版号路径）
- 主办者信息：填**个人**信息（与账号主体一致）

🧑 **2.2 填写游戏信息**（材料我写好了 → 见 `wechat/上架材料.md`）
- 游戏名称 / 类型 / 玩法简介 / 内容说明 / 是否有联网 / 是否有付费
- 附件通常要：**游戏截图 3～6 张** → 用 `wechat/screenshots/` 里我生成的
- 有的属地要求 **软件著作权证书**（软著）：如需，可在中国版权保护中心申请，个人约 30～60 天。**这一步可能拖时间，建议注册账号的同时就去申请**

🤖 **2.3 我已准备**
- `wechat/上架材料.md`：游戏简介、玩法说明、内容自审、适龄提示、技术架构说明（可直接抄进表格）
- `wechat/screenshots/`：6 张游戏截图 + 512 图标

🧑 **2.4 等审核**
- 期间可以继续开发（阶段 2 的功能），不影响已提交的备案信息

## 阶段 5 · 提交审核

🧑 **5.1 在后台创建版本并提交审核**
- 后台 →「版本管理」→ 找到刚上传的版本 →「提交审核」
- 需要填：
  - **版本说明**：首个版本，弓箭闯关休闲游戏
  - **功能页面截图**：用 `wechat/screenshots/`
  - **审核备注**（重要！审核员看这个）→ 见 `wechat/上架材料.md` 的「审核备注」，直接复制
  - **测试账号**：无（本游戏无登录）→ 填「无需账号，直接点击开始即可游玩」

🧑 **5.2 审核要点自查**
- [ ] 名称不含他人商标/IP
- [ ] 首屏有明确的游戏引导（新手引导已做 ✅）
- [ ] 没有外部链接、没有跳转网页
- [ ] 没有支付/充值入口（个人主体也做不了）
- [ ] 隐私说明已提交
- [ ] 游戏内不出现"测试""demo"等字样

🧑 **5.3 等审核**
- 一般 1～7 个工作日；被驳回会给理由，改完重新提交即可

## 阶段 6 · 发布

🧑 **6.1 审核通过后**
- 后台点「发布」→ 状态变为「已发布」
- 之后可以：搜名称、生成小程序码、右上角「···」分享给好友

🧑 **6.2 发布后建议做的**
- 后台「数据分析」看留存、时长
- 用户量起来后申请「流量主」，在游戏里接激励视频广告（比如复活、双倍金币）
- 每次更新：改代码 → 开发者工具上传 → 后台提交审核 → 发布

## 常见被驳回原因（提前避开）

1. **类目不符**：一定要选「游戏-休闲游戏」，别选工具类
2. **名称违规**：带"官方""最强"等词、或与他人商标近似
3. **无隐私说明**：后台没提交「用户隐私保护指引」
4. **备案未通过**：这是最常见的卡点，务必先备案
5. **首屏功能不完整**：点进去就报错/白屏（我们已跑通 23 项自动化测试，风险低）
6. **截图与实际不符**：截图必须是真实游戏画面（我生成的截图就是真机运行截的）
