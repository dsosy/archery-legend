# 音帝庙大冒险 · 微信小游戏版（阶段 1）

这是**能跑通的最小可玩版本**：核心玩法（闯关 / 无尽 / 升级选卡 / 暂停 / 结算）已经全部搬到 canvas 上，
不依赖任何 DOM，可以直接用微信开发者工具导入运行。

## 怎么打开

1. 下载安装 **微信开发者工具**（稳定版即可）
2. 打开 → **导入项目** → 目录选择这个 `wechat/` 文件夹
3. AppID 先选「**测试号**」（或用你自己的小游戏 AppID；`project.config.json` 里现在是 `touristappid`）
4. 点确定即可运行，模拟器里就能玩

## 目录说明

| 文件 | 作用 | 要不要手动改 |
| --- | --- | --- |
| `game.js` | **自动生成**：平台适配层 + 游戏核心 + canvas 界面 | ❌ 别改，会被覆盖 |
| `game.json` | 小游戏配置（竖屏、无状态栏） | 按需 |
| `project.config.json` | 开发者工具项目配置（记得换 AppID） | ✅ 换 AppID |
| `shims.js` | 平台适配层：把 wx 能力包装成浏览器 API | ✅ 可改 |
| `ui-canvas.js` | canvas 界面层：HUD / 菜单 / 选卡 / 暂停 / 结算 | ✅ 可改 |

**要改玩法**（数值、技能、敌人、掉落…）→ 改根目录的 `index.html`，然后执行：

```powershell
cd "D:\Documents\DeepSeek Hamess\archery-legend"
node _wxbuild.mjs
```

`game.js` 会重新生成，**网页版和小游戏版共用同一份游戏逻辑**，不会分叉。

## 阶段 1 已经实现

- ✅ 无 DOM 环境运行（小游戏没有 `document`/`window`，全部走 canvas）
- ✅ canvas 版 HUD：血条 / 护盾 / 经验条 / 等级 / 三系属性 / 金币 / 房间与剩余敌人数 / 技能栏（带层数角标）/ 冲刺按钮 / 摇杆
- ✅ canvas 版菜单（继续闯关 / 单人无尽 / 今日挑战 / 切皮肤 / 音效）
- ✅ canvas 版新手引导
- ✅ canvas 版升级选卡（先选属性三选一，再选该系技能三选一）
- ✅ canvas 版暂停（含攻击/攻速/估算 DPS/武器倍率）
- ✅ canvas 版通关 / 阵亡结算（下一关继承技能）
- ✅ 触摸操作：摇杆（双人时左右半屏分开）、按钮点击命中
- ✅ 存档走微信本地缓存 `wx.setStorageSync`
- ✅ 音效与 BGM 走 `wx.createWebAudioContext()`（与浏览器 WebAudio 同款 API）
- ✅ 切后台自动写存档（`wx.onHide`），回来继续

## 自测

小游戏版有独立的自动化测试（用 wx 模拟器 + 参数注入隔离真实 DOM）：

```powershell
node _wxbuild.mjs      # 生成 game.js
node _wxsmoke.mjs      # 生成 _wx_test.html（23 项用例）
# 然后用 Chromium 打开 _wx_test.html，或参考仓库里的测试脚本用法
```

覆盖：无 DOM 加载、菜单渲染、触摸开始游戏、摇杆移动、战斗推进、升级选卡、暂停、
存档写入、通关/阵亡结算、全程无运行期错误。三种屏幕尺寸（400×860 / 760×760 / 900×412）全部通过。

## 上线前需要你自己完成的事

1. 注册**小游戏类目**的微信账号（个人主体可注册）
2. 完成**游戏备案**（个人主体走免版号路径；政策以微信公众平台最新要求为准）
3. 在开发者工具里点「上传」，然后到公众平台**提交审核**
4. 审核要点：名称不能蹭 IP；需要有隐私说明（本游戏数据全部存在本地，不上传任何信息）
